## 1. 프로젝트 한 줄 소개

수학 문제(이미지·PDF)를 올리면 유사 문제를 정답·풀이와 함께 만들어 주는 독립 API 서비스. 초중고 전체 수학을 대상으로, 난이도와 개수를 지정할 수 있게 하는 것을 MVP 목표로 한다.

## 4. 첫 번째 사용 가능 버전(MVP)

### 핵심 기능

1. 문제 업로드: 이미지(사진/캡처) 또는 PDF로 수학 문제를 올린다. PDF는 문제 번호를 지정해 해당 문제만 처리한다.
2. 유사 문제 생성: 원본 문제를 인식해 유사 문제를 만든다. 개수 지정, 난이도 조절(더 쉽게/같게/더 어렵게) 가능.
3. 정답·풀이 제공: 생성된 각 문제에 정답과 단계별 풀이를 함께 돌려준다.
4. 정답 자동 검증: 생성된 정답을 계산으로 다시 확인한다.
5. 텍스트 입력: 이미 추출된 문제(problem-extractor 결과 JSON 등)를 그대로 보내 유사 문제를 만든다.

### 이번 MVP에서 제외할 기능
- API 키 / 로그인 (인증 없이 사용)
- 그래프·도형 그림 생성 (그림이 필요한 문제는 텍스트로만 표현) → 다음 단계
- 생성 결과 DB 저장 (요청마다 결과만 돌려줌) → 다음 단계

### 대표 사용 흐름

1. 클라이언트가 문제 이미지 또는 PDF(+문제 번호)를 개수·난이도 옵션과 함께 API로 보낸다.
2. 서버가 원본 문제를 인식한다.
3. 유사 문제를 생성하고 정답을 검증한다.
4. 문제·정답·풀이를 응답으로 돌려준다.
